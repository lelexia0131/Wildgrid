# Wildgrid / 野格 · 3D 美术参考包

## 用途
本包供 Codex 对野格现有游戏实施实时 3D 棋盘及视觉 UI 改造时参考。图片仅为设计方向，不是游戏截图、贴图集、可旋转的三维模型或最终资产；不要求直接复用图片本身。缺少的模型、材质和纹理由 AI 辅助创作、程序化建模或经授权的工具补全。

## 文件
- `references/01-miniature-campsite.png`（988 × 548）：用户提供的微缩露营棋盘美术参考。重点是草地块、针叶树、黄色帐篷、篝火、清澈水面、岩石、金色自然光与手工模型质感。
- `references/02-3d-gameplay-ui-concept.png`（1672 × 941）：AI 生成的 3D 游戏 UI 概念图。重点是倾斜俯视的方格棋盘、立体设施、地图外围景观、边缘线索、放置预览与轻量操作面板。不是实际玩法截图。

## 美术目标
- 原创、精致、温暖的微缩自然露营世界；统一的比例、材质、色彩与光照。
- 借鉴策略游戏的镜头语言：斜俯视、围绕棋盘旋转、平移、缩放、正俯视切换；始终保持方格规则及线索清晰。
- 优先实现真实 WebGL 三维几何，避免用整张概念图、平面精灵或 CSS 假 3D 代替可交互模型。
- 草地采用可重复平铺的材质，网格边缘清楚；森林、山石、水面、营地等使用适当的低至中模细节、环境光和柔和阴影。装饰不影响占格与拾取。
- 保留游戏真实的设施、地形、占格、方向、行列提示、规则错误、菜单、模式与存档；概念图中额外的资源数值、设施类别、计数图标和规则文字不能当作需求或真实游戏内容。
- 可保留传统二维模式，并与 3D 使用同一份游戏状态。

## 放置方式
建议将本包解压至 `D:\Wildgrid\steam\3d-redesign\`。此目录只放参考、建模源文件、渲染预览及报告。实际运行所依赖的 3D 代码和优化后的资源应位于项目根目录的共享源码/资源树中，不能复制一份 Steam 专用游戏源码，也不能将参考素材放进 Steam depot 构建目录。具体目录按当前项目结构适配。
