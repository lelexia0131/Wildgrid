# 野格 · 微缩营地

每次进入关卡默认打开实景营地。点“平面规划”可切换到方便数格和摆放的棋盘，两种视图共享对局。第一关在玩家实际棋盘上先示范、再引导手动切换。图纸使用平面图案。居中的首页封面使用同一批模型预渲染的循环动图，系统开启减少动态效果时显示静帧。

每格边长为 1，Y 向上，列向 +X，行向 +Z。设施原点是未旋转占格外接矩形的水平中心，地面在 Y=0。顺时针旋转对应绕 Y 转 −90°。足迹和旋转的唯一来源是 Engine 的 `offsets`。多格木屋及帐篷沿同一条连续屋脊转折。野餐桌的长凳和桌体覆盖双格中的一部分，两格都参与原来的规则判定。

用 Node.js 22+ 和本地安装的 Chrome，在项目根目录执行以下命令。也可设置 `WILDGRID_BROWSER_CHANNEL=msedge` 选用 Edge。素材处理读取本地源文件。

```powershell
npm ci
npm run art:3d
npm run dev
```

`art:3d` 导出本地 GLB、烘焙材质并在真实 WebGL 中渲染 68 张透明设施及地形视图、60 张地图预览和 5 张场景插画。手册和图纸中的多格图使用同一模型的正俯视图，设施卡片使用斜俯视角。发布包从 `dist/` 取材。可编辑源、研究记录、原始参考图和验收图片都位于发行资源树以外。

单独重新生成 48 帧封面动图可运行 `node scripts/art-3d/build-art.mjs --cover`。首页播放本地 WebP，进入关卡时再加载实时三维渲染器。

苹果树和梨树种在林缘或草甸，湿岸分布垂柳与白桦，林下和路旁点缀苔木、蘑菇、树桩与路标。地面和云海实景偶尔会有小群燕子拍翅、滑翔经过。飞鸟与外景装饰都位于玩法层之外，减少动态效果时停用飞鸟。可查看[第 24 关最远镜头](previews/day24-exterior.webp)与[燕群飞过的实景片段](previews/swallow-flight.webp)。

外景小径从棋盘边缘的空地出发。溪流两侧有足够干岸才架桥，桥头与末块木板共用标高。湖湾小径沿岸转向观景点，树木、倒木与路标在铺好的通道外落地。路面、地形找坡和装饰避让使用[同一条路径](../../src/ui/board3d/footpath.ts)。[桥头和沿岸小径俯视实拍](previews/camp-paths.webp)。

## 状态与操作

React 继续拥有选择、库存、放置预览、撤销历史和当前层。Three.js 消费只读的关卡、设施位置和规则反馈。DOM 格子与 WebGL 共用一台固定 39° 镜头的透视相机，通过含齐次 w 的平面投影对齐，输入继续使用原有控件和 Engine 命令。行列边牌在屏幕空间保持正立。镜头没有存档字段，装饰物没有逻辑格。

普通拖动可从俯视连续降到地平线。缩放比例在环绕时保持稳定。鼠标缩放与双指手势用地面射线锁定指针或手指中点。森林、河床、步道、桥与云层都是场景对象，地形延伸至雾中的远方。相邻水格共享边不绘格线，水深由外岸决定。实景设施栏可贴边收起，隐藏滚动条后仍可通过滚轮、滑动和键盘浏览。选中标记是做深度测试的地面轮廓，多格屋顶保留完整几何。

布旗、桨叶与火苗是独立模型。火焰的五束火舌沿各自高度传播热浪并横向卷曲，余烬从火堆逸出。泳池有镶边池壁、入水台阶、扶梯、救生圈和独立水面。电塔从基础到顶帽连续收尖，绝缘子悬挂在桁架横担上。烟从经过设施旋转变换的烟囱与火堆位置生成。开启减少动态效果或把页面切到后台，可停下环境动画。低画质降低像素密度和外围装饰，关闭方向光阴影及烟雾。WebGL 或资源加载失败会切回经典棋盘。

Windows 的 `wildgrid://` 页面通过本地 `blob:` 读取 GLB 内嵌纹理。`electron/main.cjs` 的连接策略允许同源和这些内存对象。Windows 成品启动测试会检查实际纹理解码和首帧绘制。

按本次要求，地形 ID 统一改为 `rock`。旧外部 WG1 和含旧地形代码的求生挑战可能无法打开。存档写入保护继续保留原始记录。历史测试样本使用独立的比较代码复核改名前后的玩法，客户端只识别当前 ID。

素材许可与工具选型见[来源和研究](sources.md)，验证命令、实测数据和截图见[验收记录](validation.md)。
