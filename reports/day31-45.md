# Day 31–45 开发验收

- Day 31 以通关 Day 15 为入口；31–45 逐关解锁，与 16–30 的进度链分开。
- 31–45 全部为固定 8×8、唯一解；同类同形设施编号及等价旋转不重复计解。
- Day 1–30 地图与答案逐项匹配开发前 Git HEAD，摘要记录于 day31-preservation.json。
- 餐车、电塔、泳池复用统一规则、实际多格营地占格、三态实时提示、Solver 剪枝和 SVG。沙盒、本地地图、图纸、WG1 编码和荒野求生均支持新设施。
- 保存键与 v1 / WG1 格式保留。经验、徽章、身份和通关统计实现未改动。
- 荒野求生逐步引入新设施：低难度少量餐车，4 难起加入电塔，5 难起加入泳池；高难度可三种同时出现。保留原设施数量及奖励范围，通过合法位置筛选、搜索预算及参考布局回退控制生成耗时；结果与参考地图的结构指纹不同。

## 验证

- 29 项关键验证：统一新规则、逆序及未完成放置、多格占格、31–45 唯一解、旧关数据、手册正反例、独立解锁、WG1、新旧地图存档、挑战进度及结算兼容。初轮两处失败修复后定向复验通过，其余 27 项通过。

- TypeScript 与 Vite 生产构建通过；Windows NSIS x64 安装包与 Android debug APK 构建通过。
- Android 渲染使用同一份 Web SVG；本次未做 Android 真机实测。
